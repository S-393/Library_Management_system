
PROJECT TITLE: LIBRARY MANAGEMENT SYSTEM

1. INTRODUCTION
----------------
The Library Management System is a menu-driven application
developed using the C programming language.

It is designed to manage library book records and perform
basic library operations.

2. OBJECTIVES
-------------
- To understand modular programming in C.
- To implement file handling.
- To organize a program using header files.
- To understand the use of structures and functions.
- To manage book records through a menu-driven application.

3. TECHNOLOGIES USED
--------------------
Programming Language: C
Compiler: GCC
Operating System: Linux
Build Tool: Make

4. PROJECT FILES
----------------
main.c      - Main program and application entry point.
library.c   - Library-related operations.
library.h   - Library function declarations.
file.c      - File handling operations.
file.h      - File handling function declarations.
types.h     - User-defined data types.
books.txt   - File used to store book information.
makefile    - Automates compilation and linking.
readme.txt  - Project documentation.

5. FEATURES
-----------
- Menu-driven interface.
- Book record management.
- File handling for storing information.
- Modular implementation using multiple C files.
