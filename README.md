# Library Management System

## Project Overview

The Library Management System is a menu-driven application developed using the C programming language. It demonstrates modular programming and file handling by organizing the application into multiple source files.

//Objectives
- Develop an application using C programming.
- Implement modular programming using multiple source and header files.
- Understand file handling in C.
- Organize and maintain code using a Makefile.

//Technologies Used
- C Programming
- GCC Compiler
- Linux
- Makefile

//Project Structure
File - Description 
main.c - Main program 
library.c - Library-related operations 
library.h - Library function declarations 
file.c - File handling operations 
file.h - File handling function declarations 
types.h - User-defined data types 
books.txt - File for storing book information 
makefile - Automates compilation and linking 

// Concepts Practiced
- Functions and modular programming
- Header files
- File handling
- Separate compilation
- Compilation and linking
- Makefile usage in Linux
